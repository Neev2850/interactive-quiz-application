# Interactive Quiz Application

A responsive, dynamic quiz web application built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. Features real-time countdown timers, category filters, sound synthesizers, score calculation with speed bonuses, and comprehensive answer reviews.

## 🌟 Key Features

- **Multi-Category Question Bank**: Test your skills in Python, JavaScript, Web Development (HTML/CSS), and Computer Science fundamentals.
- **Dynamic Real-Time Timer**: 15-second countdown timer per question with visual heartbeat warning animations.
- **Speed Bonus Scoring**: Rewards players with extra points for answering quickly.
- **Web Audio API Synthesizer**: Clean synthesized sound effects for correct, wrong, and timer ticking events without external audio assets.
- **Persistent High Scores**: High scores stored locally via browser `localStorage`.
- **In-Depth Answer Review**: Review each attempted question with side-by-side correct answers and conceptual explanations.
- **Mobile-First Responsive Design**: Fluid layout optimized for mobile smartphones, tablets, and desktop displays.

## 🚀 How to Run Locally

No build tools, bundlers, or package installations are required.

1. Clone this repository:
   ```bash
   git clone https://github.com/Neev2850/interactive-quiz-application.git
   cd interactive-quiz-application
   ```
2. Open `index.html` in any modern web browser:
   - On Windows: double-click `index.html` or run `start index.html` in PowerShell.
   - Or run with a lightweight local server:
     ```bash
     python -m http.server 8000
     ```
     Navigate to `http://localhost:8000`.
